### Featured Projects

* ☕ **[`coffeesolver`](https://github.com/xng101ks/coffeesolver)** — *MATLAB / MILP*  
  A generalized optimization script modeling a bounded Diophantine equation via Mixed-Integer Linear Programming (`intlinprog`). Built to calculate exact beverage combinations that deplete leftover cent balances on prepaid campus vending machine apps down to €0.00.

* 🖱️ **[`ps2-mouse-driver-sweb`](https://github.com/xng101ks/ps2-mouse-driver-sweb)** — *C++ / Kernel Space*  
  An interrupt-driven PS/2 mouse driver implemented from scratch for SWEB, an educational operating system. Handles hardware initialization, IRQ packet parsing, and cursor state management at the kernel level.

* 📺 **[`fireos5_launcher`](https://github.com/xng101ks/fireos5_launcher)** — *Android / Fire OS*  
  A lightweight, zero-bloat custom home launcher built for legacy 2nd-gen Amazon Fire TV Sticks running Fire OS 5.5, stripping away ad-heavy UI overhead for snappy local media playback.

* 🛡️ **[`bachelor_thesis`](https://github.com/xng101ks/bachelor_thesis)** — *CAN-Bus / SDR / BLE*  
  Security evaluation and proof-of-concept exploitation of automotive embedded interfaces, demonstrating CAN-bus fuzzing on a motorcycle instrument cluster, BLE reconnaissance, and RF remote keyless entry replay attacks using Software-Defined Radio.

* 📊 **[`data_analysis_pattern_recognition_final_project`](https://github.com/xng101ks/data_analysis_pattern_recognition_final_project)** — *Python / PyTorch / Time-Series ML*  
  Comparative time-series regression study predicting urban carbon monoxide ($CO$) concentrations from the UCI Air Quality dataset. Implements chronological splitting, sensor feature normalization, and recurrent neural network architectures (GRU and LSTM) in PyTorch.
